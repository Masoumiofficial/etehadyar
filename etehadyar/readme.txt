دستیار هوشمند گفت‌وگویی برای وردپرس با ظاهر شماتیک مغز، چت متنی و صوتی و پاسخ بر اساس محتوای سایت — محصول اتحاد وردپرس.

== Description ==

اتحادیار یک دستیار هوشمند برای وردپرس است که بازدیدکنندگان می‌توانند هر سؤالی بپرسند (متنی یا صوتی) و پاسخ هوشمند دریافت کنند. ظاهر آن یک «مغز شماتیک» است — نمایهٔ سر انسان با شبکهٔ عصبی سیناپسی متحرک، به سبک blueprint.

محصول اتحاد وردپرس (etehadwp.com) — مدیر پروژه: سجاد معصومی.

ویژگی‌ها:

* چت متنی با هر مدل هوش مصنوعی (GPT / Claude / Gemini) از طریق API گپ‌جی‌پی‌تی (پرداخت ریالی).
* ورودی صوتی با Web Speech API مرورگر (رایگان و بدون سرور).
* خروجی صوتی با موتور گفتار مرورگر.
* پاسخ بر اساس محتوای سایت وردپرس (RAG) به همراه لینک منابع.
* ظاهر شماتیک مغز متحرک با رنگ قابل تنظیم.
* ویجت شناور + شورت‌کد برای جاسازی داخل صفحه.
* کلید API فقط روی سرور ذخیره می‌شود و به مرورگر نمی‌رود.
* محدودسازی نرخ درخواست برای جلوگیری از سوءاستفاده.

== Installation ==

1. پوشهٔ `etehadyar` را در `wp-content/plugins/` آپلود کنید.
2. پلاگین را از منوی «پلاگین‌ها» فعال کنید.
3. به منوی «اتحادیار» بروید و کلید API گپ‌جی‌پی‌تی و مدل را تنظیم کنید.
4. ویجت شناور خودکار ظاهر می‌شود؛ یا شورت‌کد `[etehadyar]` را در صفحهٔ دلخواه بگذارید.
